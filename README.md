# Ghost Manga 5

แปลมังงะ / มันฮวา / มานฮวาในหน้าเว็บเป็นภาษาไทย (ปรับปรุงใหม่ทั้งหมดจาก Ghost Manga UI v4.0)

## มีอะไรใหม่

| ปัญหาเดิม (v4) | v5 แก้ยังไง |
|---|---|
| ตัวอักษรจีน/ญี่ปุ่น/เกาหลีแนวตั้งกลายเป็นแถบแนวนอนเล็กๆ ไม่พอดีช่องคำพูด | อ่านตัวหนังสือเอง รวมคอลัมน์แนวตั้งเป็น 1 ช่องคำพูด ลบตัวเดิม แล้วจัดวางภาษาไทยใหม่ให้พอดีช่อง (สระ/วรรณยุกต์ซ้อนถูกต้อง ตัดคำไทยตามพจนานุกรม) |
| แปลแบบ "Google แปล" | แปลทั้งหน้าในครั้งเดียวด้วย AI (ในเครื่องฟรี / Gemini / Claude) รู้บริบท จำชื่อตัวละคร ใช้ครับ/ค่ะ/นะ ตามคนพูด |
| หลายเว็บแปลไม่ได้ | ดึงรูปจากแคชของ Chrome โดยตรง (ไม่ต้องโหลดใหม่ จึงไม่โดนบล็อก) + ทางสำรองอีก 4 ทาง รองรับ lazy-load, `<picture>`, รูปที่วาดบน canvas, webtoon ยาวๆ, เว็บที่ใช้ CSP |
| ไฟล์ 114 MB เปิดช้า | ตัดไลบรารีที่ไม่ใช้ออก ไม่ต้องแตกไฟล์ทุกครั้งที่เปิด |
| บั๊ก: รูปที่โหลดทีหลังไม่ถูกแปล, ปิด Chrome แล้วกดเริ่มไม่ได้, แปลพลาดแบบเงียบๆ | แก้ทั้งหมด + มีปุ่มแปลรูปที่พลาดใหม่ |

## วิธีใช้

1. เปิด `GhostManga5.exe` (หรือ `run.bat` ถ้ารันจากซอร์ส)
2. วางลิงก์หน้ามังงะ → เลือกภาษา/ตัวแปล → กด **▶ เริ่มแปล**
3. Chrome จะเปิดขึ้นมา อ่านได้ตามปกติ รูปที่กำลังอ่านอยู่จะถูกแปลก่อน (มุมขวาล่างบอกความคืบหน้า)
4. กด **Alt+T** ในหน้าเว็บ เพื่อสลับดูต้นฉบับ/คำแปล
5. เปลี่ยนตอนได้เลยใน Chrome โปรแกรมจะแปลหน้าใหม่ให้เอง
6. ติ๊ก "บันทึกอัตโนมัติ" หรือกด **💾 บันทึกตอนนี้** — รูปจะถูกเก็บแยกโฟลเดอร์ตามชื่อตอน

## เลือกตัวแปล

| ตัวแปล | ค่าใช้จ่าย | คุณภาพ | ตั้งค่า |
|---|---|---|---|
| Google แปลฟรี | ฟรี | เท่า Google แปล | ไม่ต้องทำอะไร |
| **AI ในเครื่อง (แนะนำ)** | ฟรี | ดี (ขึ้นกับโมเดล) | ดูด้านล่าง |
| Gemini | มีโควตาฟรีรายวัน | ดีมาก | ใส่ API key จาก aistudio.google.com |
| Claude | เสียเงินตามการใช้ | ดีมาก | ใส่ API key จาก platform.claude.com |

ถ้า AI ตอบไม่ได้ (ปิดอยู่/โควตาหมด) โปรแกรมจะใช้ Google แปลแทนอัตโนมัติ และเขียนบอกใน log
(ถ้า key ผิด/โควตาวันนี้หมด จะเปลี่ยนไปใช้ Google ทันทีจนกว่าจะกดเริ่มใหม่ ไม่ต้องรอทุกหน้า)

หมายเหตุ: Gemini แบบโควตาฟรี Google อาจนำข้อความที่ส่งไปใช้ปรับปรุงบริการ — ถ้าไม่ต้องการ ใช้ AI ในเครื่องแทน

### ตั้งค่า AI ในเครื่อง (ฟรี) ด้วย LM Studio

เครื่องนี้ใช้การ์ดจอ AMD RX 6700 XT (VRAM 12 GB) + RAM 16 GB → รันโมเดลขนาด 7–14B ได้สบาย

1. ดาวน์โหลดและติดตั้ง **LM Studio** จาก lmstudio.ai (รองรับการ์ดจอ AMD ผ่าน Vulkan)
2. ในแท็บค้นหาโมเดล ดาวน์โหลดโมเดลที่เก่งภาษาไทย เช่น
   - **Gemma 3 12B Instruct** (แบบ Q4_K_M ประมาณ 7–8 GB) — เก่งหลายภาษา ดูรูปได้
   - หรือค้นหา **Typhoon** (โมเดลภาษาไทยโดยเฉพาะ) ถ้ามีรุ่นที่ขนาดพอดีกับการ์ดจอ
3. ไปที่แท็บ **Developer** → โหลดโมเดล → กด **Start Server**
4. ในโปรแกรมเลือกตัวแปล "AI ในเครื่อง" → กด "ตั้งค่าตัวแปล…" → "ทดสอบการเชื่อมต่อ"

Ollama ก็ใช้ได้ (ใส่ Server URL เป็น `http://localhost:11434/v1`)

## เคล็ดลับ

- **ชื่อตัวละคร**: ใส่ในแท็บ "คำแปล/ชื่อตัวละคร" เช่น `タロウ = ทาโร่` แล้ว AI จะใช้คำเดิมทุกครั้ง (AI จะจำชื่อใหม่ที่เจอเองด้วย)
- **ส่งภาพให้ AI ดูด้วย**: AI รู้ว่าใครพูด เพศอะไร แปลน้ำเสียงได้ดีขึ้น แต่ช้าลง (ต้องใช้โมเดลที่ดูภาพได้)
- **เว็บที่ต้องล็อกอิน / ติด Cloudflare**: ผ่านครั้งเดียวใน Chrome ที่โปรแกรมเปิด แล้วโปรแกรมจะจำไว้
- ถ้าขึ้นว่า **"เว็บนี้บล็อกการแสดงรูปที่แปลแล้ว (CSP)"** ให้กด F5 รีโหลดหน้า 1 ครั้ง
- รูปที่เคยแปลแล้วจะถูกเก็บในแคช เปิดตอนเดิมซ้ำจะขึ้นทันทีไม่เปลือง

## ข้อจำกัด

- การอ่านตัวหนังสือใช้ Google Lens และ Google แปลแบบไม่เป็นทางการ (ฟรี) ถ้า Google เปลี่ยนระบบอาจใช้ไม่ได้ชั่วคราวจนกว่าจะอัปเดต
- ยังไม่รองรับรูปที่อยู่ใน iframe ของโดเมนอื่น
- ตัวอักษรเอฟเฟกต์ (SFX) ที่วาดมือบนภาพ อาจอ่านไม่ออกหรือลบไม่เนียน

## ไฟล์ของโปรแกรม

- การตั้งค่า: `%APPDATA%\GhostManga5\settings.json` (API key เก็บในไฟล์นี้แบบไม่เข้ารหัส อย่าแชร์ไฟล์นี้)
- แคชรูป + โปรไฟล์ Chrome: `%LOCALAPPDATA%\GhostManga5\` (แคชลบของเก่าเองเมื่อเกิน 800 MB)
