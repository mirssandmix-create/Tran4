<h1 align="center">PoomCatoManga</h1>

<p align="center">อ่านมังงะ มันฮวา มานฮวา ในหน้าเว็บเป็นภาษาไทย — แปลแล้ววางคำแปลลงในช่องคำพูดให้เลย</p>

## ดาวน์โหลด

ไปที่หน้า [Releases](../../releases) → ดาวน์โหลด `PoomCatoManga-v5.0.0-windows.zip` → แตกไฟล์ → เปิด `PoomCatoManga.exe`

- ต้องมี Google Chrome ในเครื่อง
- ถ้า Windows ขึ้นหน้าจอสีน้ำเงินเตือน กด "More info" → "Run anyway" (โปรแกรมยังไม่มีลายเซ็นดิจิทัล)
- เก็บไฟล์ทั้งโฟลเดอร์ไว้ด้วยกัน อย่าย้ายเฉพาะไฟล์ .exe

## ทำอะไรได้บ้าง

- **ตัวหนังสือแนวตั้ง จีน/ญี่ปุ่น/เกาหลี** อ่านแล้วรวมคอลัมน์เป็นช่องคำพูดเดียว ลบตัวเดิม แล้ววางภาษาไทยแนวนอนให้พอดีช่อง (สระ/วรรณยุกต์ซ้อนถูกต้อง ตัดคำไทยไม่ขาดกลางคำ)
- **แปลทั้งหน้าในครั้งเดียว** ด้วย AI (ในเครื่องฟรี / Gemini / Claude) รู้บริบท จำชื่อตัวละคร เลือก ครับ/ค่ะ/นะ ตามคนพูด — หรือใช้ Google แปลฟรีก็ได้
- **ใช้ได้กับหลายเว็บ** ดึงรูปจากแคชของ Chrome โดยตรง รองรับ lazy-load, `<picture>`, รูปที่วาดบน canvas, เว็บตูนยาวๆ, เว็บที่อ่านทีละหน้า
- **รูปที่กำลังอ่านอยู่แปลก่อน** เลื่อนอ่านได้เลย และกด **Alt+T** ในหน้าเว็บเพื่อสลับดูต้นฉบับ/คำแปล
- **ตอนที่เคยแปลแล้วขึ้นทันที** (เก็บไว้ในแคช)

## วิธีใช้

1. **วางลิงก์** ของหน้าอ่านตอน (หน้าที่มีรูปมังงะ)
2. **เลือกภาษาและตัวแปล** — ถ้ายังไม่ได้ตั้งค่า AI ให้ใช้ "Google แปล (ฟรี)"
3. กด **▶ เริ่มอ่านและแปล** — Chrome จะเปิดขึ้นมา อ่านได้ตามปกติ การ์ดสถานะจะบอกว่าแปลไปกี่หน้าแล้ว

ปุ่มเพิ่มเติมระหว่างแปล: **⇄ ต้นฉบับ / คำแปล**, **↻ แปลที่พลาดใหม่** และกด "รายละเอียดการทำงาน" เพื่อดู log

## หน้าตั้งค่า (⚙ ตั้งค่า)

| เมนู | ใช้ทำอะไร |
|---|---|
| AI ในเครื่อง / Gemini / Claude / OpenAI | ใส่ Server URL, API key, ชื่อโมเดล |
| ชื่อตัวละคร | คำที่ต้องแปลแบบเดิมเสมอ เช่น `タロウ = ทาโร่` |
| ตัวหนังสือและธีม | ธีมมืด/สว่าง, ฟอนต์คำแปล, ขนาดตัวอักษร |
| บันทึกรูป | **ปิดไว้เป็นค่าเริ่มต้น** — เปิดเมื่อต้องการเก็บรูปที่แปลแล้ว (เลือกโฟลเดอร์ / บันทึกอัตโนมัติ) แล้วปุ่ม "บันทึกตอนนี้" จะโผล่ในหน้าหลัก |
| ขั้นสูง | จำนวนรูปที่แปลพร้อมกัน, ขนาดรูปขั้นต่ำ, จำการล็อกอินเว็บ |

## เลือกตัวแปล

| ตัวแปล | ค่าใช้จ่าย | คุณภาพ |
|---|---|---|
| Google แปล | ฟรี | เท่า Google แปล |
| AI ในเครื่อง (LM Studio / Ollama) | ฟรี | ดี (ขึ้นกับโมเดลและการ์ดจอ) |
| Gemini | มีโควตาฟรีเล็กน้อย / จ่ายตามใช้ | ดีมาก |
| Claude | จ่ายตามใช้ | ดีมาก–ดีที่สุด |

ถ้า AI ตอบไม่ได้ (ไม่ได้เปิด / key ผิด / โควตาหมด) โปรแกรมจะใช้ Google แปลแทนอัตโนมัติ

### AI ในเครื่องด้วย LM Studio
1. ติดตั้ง **LM Studio** จาก lmstudio.ai (การ์ด AMD ใช้ runtime แบบ Vulkan)
2. ดาวน์โหลดโมเดลที่เก่งภาษาไทย เช่น **Gemma 3 12B** (Q4_K_M ~7–8 GB) หรือค้นหา **Typhoon**
3. แท็บ **Developer** → โหลดโมเดล → **Start Server**
4. ใน PoomCatoManga: ตัวแปล "AI ในเครื่อง (ฟรี)" → ⚙ ตั้งค่า → "ทดสอบการเชื่อมต่อ"

## ข้อจำกัด

- การอ่านตัวหนังสือใช้ Google Lens และ Google แปลแบบไม่เป็นทางการ (ฟรี) ถ้า Google เปลี่ยนระบบอาจใช้ไม่ได้ชั่วคราว
- ยังไม่รองรับรูปที่อยู่ใน iframe ของโดเมนอื่น
- ตัวอักษรเอฟเฟกต์ (SFX) ที่วาดมือบนภาพ อาจอ่านไม่ออกหรือลบไม่เนียน

## ไฟล์ของโปรแกรม

- การตั้งค่า: `%APPDATA%\PoomCatoManga\settings.json` (API key เก็บแบบไม่เข้ารหัส อย่าแชร์ไฟล์นี้)
- แคชรูป, โปรไฟล์ Chrome, `log.txt`: `%LOCALAPPDATA%\PoomCatoManga\`
